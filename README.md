# kestermckinney.github.io

Static GitHub Pages site for Paul McKinney and the featured projects:

- [ProjectNotes](https://github.com/kestermckinney/ProjectNotes)
- [SqliteSyncPro](https://github.com/kestermckinney/SqliteSyncPro)
- [SeeMyMac](https://github.com/kestermckinney/SeeMyMac)
- [ScheduleIO](https://github.com/kestermckinney/ScheduleIO)

The site uses plain HTML and CSS; it does not require a build step. To preview it locally, serve the repository root with a static web server.

GitHub Pages publishes the root of the `main` branch at <https://kestermckinney.github.io/>. Project links assume the repositories are mirrored under the same names on GitHub.
