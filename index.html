About

Professional profile

I currently work in the Cornerstone Controls ecosystem, where digital solutions, automation, data management, and project management come together to support manufacturers across industries such as life sciences, food and beverage, energy, chemicals, and consumer products.

My background blends formal project leadership with hands-on technical fluency. That combination helps me translate between operations teams, technical contributors, and business stakeholders so projects move from requirements to results with less friction and more clarity.

Outside of my professional work, I build software that reflects the way real project work happens: meetings, action items, data, reporting, follow-up, and the need to keep systems aligned across desktop, mobile, and cloud environments.

Personally, I am motivated by useful tools, steady leadership, and work that helps teams stay organized without adding more noise. I care about practical improvement, thoughtful documentation, and building things that continue to help people after the kickoff meeting is over.

Sqlite Sync Pro

A Qt/C++ synchronization library for offline-first applications that need to keep local SQLite data aligned with PostgreSQL through PostgREST or Supabase-style patterns.

  • Bidirectional push-pull sync design
  • Encryption, authentication, and worker-thread architecture
  • Built to support desktop and mobile application scenarios

SeeMyMac

I’m building SeeMyMac with Rust and GPUI to give Windows and Linux users a more responsive way to connect to a Mac. It uses Apple’s High Performance Screen Sharing for video, alongside standard Virtual Network Computing (VNC).

  • Saved computers, search, and favorites
  • Apple High Performance video and standard VNC
  • Built with Rust and GPUI

ScheduleIO

A cross-platform Qt/C++ library for reading, creating, editing, scheduling, and converting Microsoft Project plans. It supports native MPP files and Microsoft Project-compatible XML without requiring Microsoft Project to be installed.

  • Reads MPP12 and MPP14 project files
  • Reads and writes Microsoft Project XML
  • Shared project model for scheduling and file conversion
