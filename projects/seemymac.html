Meet SeeMyMac.

I’m building SeeMyMac to give Windows and Linux users a more responsive way to connect to a Mac, using Apple’s High Performance Screen Sharing video.

View on GitLab ↗Explore more projects
The idea

Keep your Mac within reach.

I started SeeMyMac because many Windows and Linux remote desktop apps rely on standard Virtual Network Computing (VNC), which can be slow when connecting to a Mac. I wanted a client that could use Apple’s High Performance Screen Sharing video for a more responsive experience.

SeeMyMac brings saved computers and remote viewing into one desktop workspace. Search and organize connections, discover Macs on the local network, and connect to a remote display.

SeeMyMac runs on Windows, Linux, and macOS, and remains in active development.

Features

Made for the way you connect.

Organize computers

Save connection details, search the list, mark favorites, and return to recent computers.

Find and connect

Connect to a Mac using Apple High Performance Screen Sharing or standard VNC.

Work remotely

View and work with a remote Mac using high-performance video, keyboard, and mouse input.

A closer look at SeeMyMac.

Under the hood

Built in the open.

SeeMyMac is built in Rust with GPUI. Its Apple High Performance protocol and video decoding are implemented in Rust, without an external Python bridge. The repository includes development notes, tests, and the current validation status.
